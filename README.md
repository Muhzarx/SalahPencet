## 🕹️ Tentang Game

SALAH PENCET! adalah game browser sederhana yang menguji kecepatan membaca, fokus, dan refleks. Instruksi akan berubah-ubah dan tempo permainan semakin cepat setiap ronde. Jangan asal klik!

## ✨ Fitur

- ⚡ Gameplay cepat dengan tingkat kesulitan yang meningkat.
- 🧠 Instruksi yang menguji fokus dan refleks.
- 🏆 Skor, ronde, dan rekor tertinggi tersimpan di browser.
- 🔊 Efek suara sintetis.
- 📱 Tampilan responsif untuk desktop dan perangkat mobile.
- 📤 Bagikan skor dan tantang temanmu.
- 🌐 Gratis dimainkan langsung dari browser, tanpa perlu mengunduh aplikasi.

## 🚀 Mainkan

**[👉 KLIK DI SINI UNTUK BERMAIN](https://muhzarx.github.io/SalahPencet/)**

> Jika demo belum terbuka, aktifkan GitHub Pages terlebih dahulu melalui **Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save**. Pastikan `index.html` berada di root repository. Setelah deployment selesai, coba buka kembali tautan demo.

## 🎯 Cara Bermain

1. Tekan **GAS MAIN**.
2. Baca instruksi yang muncul di layar.
3. Klik tombol yang sesuai secepat mungkin.
4. Jangan salah memilih dan jangan kehabisan waktu.
5. Kumpulkan skor setinggi mungkin, lalu bagikan hasilmu!

## 🛠️ Teknologi

- HTML5
- CSS3
- JavaScript (Vanilla)
- Local Storage API
- Web Share API (dengan fallback clipboard)

Tidak membutuhkan framework, backend, database, atau proses build.

## 📦 Jalankan di Komputer

1. Clone repository ini:
   ```bash
   git clone https://github.com/Muhzarx/SalahPencet.git
   ```
2. Masuk ke folder project:
   ```bash
   cd SalahPencet
   ```
3. Buka `index.html` di browser.

## 🌍 Hosting Gratis dengan GitHub Pages

Repository ini dapat di-host menggunakan GitHub Pages:

1. Buka tab **Settings** pada repository.
2. Pilih **Pages** di sidebar.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch `main` dan folder `/ (root)`.
5. Klik **Save**, lalu tunggu proses deployment selesai.
