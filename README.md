# SALAH PENCET! 😭

Game refleks absurd berbahasa Indonesia. Baca instruksi, pilih tombol yang tepat, dan jangan sampai salah pencet!

## Mainkan secara lokal
Buka `index.html` di browser. Tidak perlu instalasi atau build.

## Deploy ke GitHub Pages
1. Upload `index.html` dan `README.md` ke root repository.
2. Buka **Settings → Pages**.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
5. Tunggu GitHub Pages menerbitkan situs.

## Fitur
- Gameplay cepat dengan tingkat kesulitan meningkat.
- Skor, ronde, dan rekor tertinggi tersimpan di browser.
- Efek suara sintetis tanpa file audio tambahan.
- Tombol berbagi skor menggunakan fitur share perangkat atau clipboard.
- Tampilan responsif untuk desktop dan ponsel.

> Game ini dibuat sebagai proyek original. Potensi viral tidak bisa dijamin—bagikan link, rekam reaksi bermain, dan ajak teman memecahkan rekor.
